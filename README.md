# WHAT IS ITD

ITD is a custom experimental symbolic communication architecture.

Instead of traditional readable messaging, GHOSTNET automatically transforms text into dynamically mutated symbolic outputs before transmission.

Example:

```txt id="8mb2sv"
hello
↓
Ȣɕⱥƻȡȴɟↄɿ
```

Messages appear encrypted by default.

Each message contains:

```txt id="u9q4rx"
[ DECRYPT ]
```

When clicked:

* the original readable text becomes visible locally.

# HOW TO USE

## CREATE SESSION

1. Open GHOSTNET
2. Enter a temporary alias
3. Click:
   `INITIALIZE SESSION`
4. A temporary room cipher will be generated
5. Share the room cipher with anyone you want to communicate with

Example:

```txt id="v6k1pt"
S9-JWQ-FXXJF
```

---

## JOIN SESSION

1. Open GHOSTNET
2. Enter temporary alias
3. Paste shared room cipher
4. Click:
   `CONNECT`

You will instantly join the same secure relay environment.

The system supports:

* private sessions
* multi-user relay rooms
* realtime communication

5+ users can join the same room simultaneously.
